# 💍 Convite Virtual de Casamento

Aplicação web interativa e responsiva desenvolvida para servir como um convite virtual de casamento, facilitando a organização do evento e oferecendo uma experiência simples e intuitiva para os convidados.

---

## 📌 Descrição

O projeto foi desenvolvido para resolver problemas práticos de logística de eventos, reunindo em um só lugar as informações essenciais do casamento, como data, horário, localização, confirmação de presença (RSVP) e lista de presentes.

---

## ✨ Funcionalidades

* **Interface Responsiva:** Adaptada para navegação em dispositivos móveis (smartphones) e computadores.
* **Confirmação de Presença (RSVP):** Formulário simples para que os convidados confirmem presença.
* **Informações do Evento:** Exibição clara de data, horário e localização com mapa/endereço.
* **Lista de Presentes:** Organização e direcionamento de presentes para os noivos.
* **Design Personalizado:** Layout clean e focado em UX (User Experience).

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura das páginas e semântica do projeto.
* **CSS3:** Estilização, layout responsivo e transições visuais.
* **JavaScript:** Interatividade da página e validações de formulário.
* **GitHub Pages:** Hospedagem do projeto para acesso público.

---

## 🎯 Objetivo

Oferecer uma solução digital moderna para a gestão de informações e presença em eventos, aplicando boas práticas de front-end, usabilidade e design responsivo.
